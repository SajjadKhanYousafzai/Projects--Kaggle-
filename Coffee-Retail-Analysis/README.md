# Coffee Retail Analysis

End-to-end analytics notebook for coffee retail sales data, including:

- Data loading and validation
- Data cleaning and merging
- Feature engineering
- Exploratory data analysis (EDA)
- Customer segmentation insights

## Project Files

- `coffee_analysis_complete.ipynb`: Main analysis notebook
- `Dataset/`: Input data folder (Excel dataset)
- `All images of VIsualizations/`: Exported visualizations

## Setup

1. Create and activate a Python environment.
2. Install dependencies:

```bash
pip install -r requirements.txt
```

## Run

Open and run:

- `coffee_analysis_complete.ipynb`

If your dataset path differs, update `LOCAL_PATH` in the notebook to point to your local Excel file.

## Dataset

Notebook expects the Coffee Analysis Excel dataset (orders, customers, products sheets).
